## Root Cause

The key was shared in chat during a prior session and was:
1. Logged to session memory (`memory/2026-08-07.md`)
2. Indexed by semantic search (`.dreams/short-term-recall.json`)
3. Stored in `.env` for local reference
4. **Reused** during the 2026-08-15 Stripe wiring task because the agent had access to it

The agent did not have a policy prohibiting acceptance of live keys through chat.
