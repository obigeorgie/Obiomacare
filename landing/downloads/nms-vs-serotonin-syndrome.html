🧠 NMS vs Serotonin Syndrome — Emergency Differentiation

Obioma Care | NCLEX Study Guide | obiomacare.com

🚨 BOTH ARE MEDICAL EMERGENCIES

Call provider immediately. Stop offending agents. Supportive care + specific treatments.

MentalStupor, coma, mutismAgitation, confusion, restlessness

TreatmentStop offending drug. Dantrolene. Bromocriptine. Cooling. Supportive.Stop offending drugs. Cyproheptadine (serotonin antagonist). Supportive. Benzodiazepines.

💊 NMS-Causing Drugs

Typical antipsychotics: Haloperidol, chlorpromazine, fluphenazine

Atypical antipsychotics: Risperidone, olanzapine, quetiapine, aripiprazole

Other: Metoclopramide, prochlorperazine, promethazine

Risk factors: High dose, rapid titration, dehydration, agitation, iron deficiency

💊 Serotonergic Drugs

SSRIs: Fluoxetine, sertraline, paroxetine, citalopram, escitalopram

SNRIs/MAOIs: Venlafaxine, duloxetine, phenelzine, tranylcypromine

Other: Tramadol, fentanyl, triptans, linezolid, St. John's Wort, MDMA

Risk: ANY combination of 2+ serotonergic agents (especially MAOI + SSRI)

✅ NCLEX Memory Trick: "HUNTER" vs "FEVER"

HUNTER Serotonin Toxicity Criteria (SS):

  • • Clonus (spontaneous, inducible, or ocular) + agitation or diaphoresis
  • • Clonus + hypertonia + fever >38°C
  • • Ocular clonus + agitation or diaphoresis
  • • Tremor + hyperreflexia
  • • Hypertonia (lower > upper extremities) + fever + ocular clonus

NMS = FEVER + RIGIDITY + MENTAL STATUS CHANGE + AUTONOMIC INSTABILITY

Key distinction: SS = clonus/hyperreflexia (upper > lower) | NMS = rigidity (lead pipe), bradyreflexia
