## Decision Tree 1: The "Who Do You See First?" Framework

When multiple patients need you and you're the only nurse, use this tree:

```
                    START
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
    TIER 1       TIER 2         TIER 3
   (Go NOW)    (Go soon)      (Delegate?)
        │             │             │
        ▼             ▼             ▼
   Airway        Chest pain      Pain control
   Breathing     Neuro changes   Routine meds
   Circulation   Sepsis signs    Discharge
   Active bleed  New O2 need     Education
   Code/RRT      Severe pain     Documentation
        │             │             │
        ▼             ▼             ▼
   ┌─────────────────────────────────────┐
   │  Can anything be delegated?         │
   │  YES → Delegate TIER 3, handle TIER 1-2 │
   │  NO → Handle in order of urgency    │
   └─────────────────────────────────────┘
```

## 10 Practice Scenarios

### Scenario 1: Medical-Surgical Floor

**Your assignment: 4 patients**

- **Room 1**: Post-op appendectomy, day 2. Pain 6/10, distended abdomen, no bowel sounds, last BM 3 days ago (pre-op).
- **Room 2**: CHF exacerbation, 82-year-old. SpO2 91% on 2L, RR 24, crackles bilaterally.
- **Room 3**: DKA, insulin drip running. Blood glucose 280, K+ 3.2, urine output 400mL last 8 hours.
- **Room 4**: Fall risk patient, mild dementia, trying to get out of bed, family at bedside.

**Question**: Who do you see first and why?

<details>
<summary>Answer & Rationale</summary>

**Priority Order: Room 2 → Room 3 → Room 1 → Room 4**

**Room 2 (First)**: Respiratory compromise + CHF = potential flash pulmonary edema. SpO2 91% on O2 is concerning. Need to assess breath sounds, possibly titrate O2, prepare for Lasix.

**Room 3 (Second)**: DKA with hypokalemia (K+ 3.2). Insulin drives K+ into cells, worsening hypokalemia. Cardiac risk. Need to check protocol for K+ replacement.

**Room 1 (Third)**: Post-op ileus likely, but stable. Pain control + NGT placement likely needed.

**Room 4 (Fourth)**: Delegate to tech/CNA for sitter. Safety issue but not immediately life-threatening.
</details>

### Scenario 2: Emergency Department

**You're triaging. Three patients arrive simultaneously:**

- **Patient A**: 34-year-old, "I think I have the flu." Temp 101.2, sore throat, otherwise healthy.
- **Patient B**: 67-year-old, "My chest feels heavy." BP 168/94, HR 96, pain 4/10, diaphoretic.
- **Patient C**: 5-year-old, fell from jungle gym. Crying, holding right arm, deformity visible.

**Question**: Triage order?

<details>
<summary>Answer & Rationale</summary>

**Triage Order: B → C → A**

**Patient B (First)**: Possible ACS. "Heavy" chest + diaphoresis = cardiac until proven otherwise. EKG within 10 minutes.

**Patient C (Second)**: Deformity = possible fracture. Needs x-ray, pain control. Stable but uncomfortable.

**Patient A (Third)**: Likely viral illness. Lowest acuity. Can wait.
</details>

### Scenario 3: Oncology Unit

**You have 3 patients:**

- **Patient A**: Neutropenic (ANC 400), temp 100.8°F. Last chemo 7 days ago.
- **Patient B**: Post-op Whipple procedure, day 3. NGT output suddenly increased, bilious, 800mL last 4 hours.
- **Patient C**: End-stage cancer, comfort measures only. Family requesting pain medication. Patient grimacing, moaning.

**Question**: Priorities?

<details>
<summary>Answer & Rationale</summary>

**Priority Order: A → C → B**

**Patient A (First)**: Neutropenic fever = medical emergency. Even low-grade temp in neutropenic patient is concerning. Obtain cultures, start broad-spectrum antibiotics per protocol.

**Patient C (Second)**: Comfort measures = still priority. Pain is what the patient says it is. Administer PRN pain med.

**Patient B (Third)**: Increased NGT output concerning but not immediately life-threatening. Assess for obstruction, notify MD.
</details>

### Scenario 4: Code Blue Response

**You're a new grad. Code called on your unit. You arrive to find:**

- Patient unresponsive
- No pulse
- RN from next unit is running the code
- RT is managing airway
- Another nurse is doing compressions

**Question**: What do YOU do?

<details>
<summary>Answer & Rationale</summary>

**Your role as new grad in a code:**

1. **Document**: Someone needs to record times, meds, rhythms. This is a perfect role for a new grad.
2. **Runner**: Get supplies, call family, fetch equipment.
3. **Compressions**: If asked, do compressions. Switch every 2 minutes.

**What NOT to do:**
- Don't try to run the code (not your role yet)
- Don't crowd the bed
- Don't leave unless assigned a task

**The key**: Codes are team events. Find a role and fill it.
</details>

## Quick Reference Cards

### Vital Signs: When to Worry

| Vital Sign | Concern Threshold | Action |
|------------|-------------------|--------|
| SBP | <90 or >180 (symptomatic) | Notify MD |
| DBP | >110 | Monitor, notify if symptomatic |
| HR | <50 or >120 | Assess, notify MD |
| RR | <10 or >30 | Check SpO2, notify MD |
| SpO2 | <92% on room air | Apply O2, notify MD |
| Temp | >101°F (post-op day 1-3) | Assess for infection |
| Temp | >100.4°F (neutropenic) | **EMERGENCY** |

### Lab Values: Critical Values

| Lab | Low Critical | High Critical | Common Cause |
|-----|-------------|---------------|--------------|
| K+ | <2.5 | >6.5 | DKA, renal, diuretics |
| Na+ | <120 | >160 | Dehydration, SIADH |
| Glucose | <50 | >400 | Insulin, DKA |
| Hgb | <7 | >18 (dehydration) | Bleeding, anemia |
| WBC | <2,000 | >30,000 | Infection, immunosuppression |
| Platelets | <20,000 | - | Bleeding risk |
| Creatinine | - | >4 | AKI, dehydration |
