What Is a Matrix Grid Question?

Matrix grid questions (also called "matrix multiple choice" or "grid" items) are a Next Generation NCLEX format where you select answers in a table-like grid. Each row is a statement or item, and each column is a response option.

Format Example

Intervention Indicated Contraindicated Non-Essential
Check blood glucose
Administer insulin

Where You'll See Them

  • Infection control precautions (Standard, Contact, Droplet, Airborne)
  • Medication classifications (prototype drug for each class)
  • Vital sign interpretation (normal vs abnormal by age)
  • Nursing interventions (priority, indicated, contraindicated)
  • Delegation decisions (RN, LPN, UAP, provider)

How Scoring Works — Partial Credit!

This is the ONLY NCLEX question format that awards partial credit. Understanding the scoring model is key to your strategy.

+/- Scoring (Most Common)

  • Correct selection: +1 point
  • Incorrect selection: -1 point
  • Net score cannot go below 0 for that row

Example: A row has 1 correct and 3 incorrect options.

  • Select correct + leave others blank = +1 point
  • Select correct + 1 wrong = 0 points (1 - 1 = 0)
  • Select correct + 2 wrong = 0 points (net can't be negative)
  • Select 2 wrong, miss correct = 0 points

Key Strategy: If you're unsure about an option, it's better to leave it blank than guess. A wrong answer cancels a right answer. When in doubt, don't select.

All-or-Nothing Scoring (Less Common)

Some matrix items require ALL correct selections to get credit — no partial credit. The item stem will usually specify this.

The 4-Step Matrix Strategy

Step 1: Read the STEM First

Don't look at the grid yet. Understand the clinical scenario, patient condition, and what the question is asking.

Step 2: Identify the Category System

What are the column options? Common systems:

  • Priority: First, Second, Third, Not a Priority
  • Indication: Indicated, Contraindicated, Non-Essential
  • Precautions: Standard, Contact, Droplet, Airborne
  • Personnel: RN, LPN/LVN, UAP, Provider

Step 3: Evaluate Each Row Independently

Don't try to solve the whole grid at once. Take one row at a time:

  1. Read the intervention/statement
  2. Ask: "Is this indicated, contraindicated, or non-essential?"
  3. If 100% sure → select
  4. If unsure → leave blank
  5. If definitely wrong → avoid (don't risk the -1)

Step 4: Review Before Submitting

Check that you haven't made these common errors:

  • Selected an option you were unsure about
  • Contradicted yourself (e.g., marked "check BP" as both indicated AND contraindicated)
  • Missed an obviously correct answer

Practice Matrix Question

Scenario

A nurse is caring for a patient with suspected pulmonary tuberculosis. The provider has ordered airborne precautions.

For each nursing action, click whether it is Required, Not Required, or Contraindicated for airborne precautions:

Nursing Action Required Not Required Contraindicated
Place patient in negative pressure room
Wear N95 respirator
Wear surgical mask
Keep door closed
Limit transport — mask patient if unavoidable

Explanation

  • Negative pressure room: REQUIRED — essential for airborne isolation
  • N95 respirator: REQUIRED — surgical mask is insufficient for airborne
  • Surgical mask: NOT REQUIRED — N95 is needed instead
  • Door closed: REQUIRED — maintains negative pressure
  • Limit transport + mask: REQUIRED — minimize airborne particle spread
