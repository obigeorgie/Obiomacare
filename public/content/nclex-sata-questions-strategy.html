How to Beat SATA Questions on NCLEX: The True/False Method

Select All That Apply questions are the most feared on NCLEX. But with the right strategy, they become your easiest points.

By Nnamdi Okorafor, RN · 15-year ER nurse · Updated July 2026 · Obioma

The #1 mistake nursing students make: They treat SATA questions like multiple-choice questions. They look for the "best" answer or try to find patterns. This is wrong. SATA questions require a completely different mental model.

Why SATA Questions Are Different

Standard NCLEX questions ask: "What is the BEST answer?" SATA questions ask: "Which of these are TRUE?" Each option is evaluated independently. There is no "best" — only true or false.

This means every SATA question is actually 4-6 true/false questions disguised as one. Once you understand this, the strategy becomes obvious.

The True/False Method: Step by Step

Step 1: Cover the Answer Choices

Read the question stem FIRST. Do not look at the options yet. Ask yourself: "What is this question really asking?" Identify the patient problem, the context, and what the nurse needs to do.

Step 2: Turn Each Option Into a Statement

Read each option and add the question stem to make it a complete sentence. Then ask: "Is this statement true for this patient?"

Step 3: Evaluate Each Option Independently

This is the critical step. Do NOT compare options to each other. Each option stands alone.

Ask for EACH option:

  • Is this action appropriate for this patient?
  • Is this finding significant?
  • Would this intervention help, harm, or do nothing?

Step 4: Select All That Are TRUE

If you're unsure about an option, ask yourself: "Is there any reason this would be WRONG?" If you can't find a reason it's wrong, it's probably right. When in doubt on SATA, select it.

Live Example: Apply the Method

A nurse is caring for a patient with heart failure who reports increasing shortness of breath. Which findings should the nurse report to the provider immediately? (Select all that apply.)
Weight gain of 3 lbs in 24 hours — TRUE. Rapid weight gain in HF indicates fluid retention.
Crackles in bilateral lung bases — TRUE. New crackles suggest pulmonary edema.
BP 128/78 — FALSE. This is within normal range, not immediately concerning.
Oxygen saturation 89% on room air — TRUE. Below 92% indicates hypoxemia.
Patient reports feeling anxious — FALSE. Anxiety is common and expected; not emergent.

The "Select All That Apply" Myths

Myth #1: "If you're unsure, don't select it"

Wrong. On SATA, uncertainty usually means the option is correct. The NCLEX wants you to recognize subtle but important findings.

Myth #2: "There are always 2-3 correct answers"

Wrong. SATA questions can have anywhere from 1 to all correct answers. Never use the number of selections as a strategy.

Myth #3: "If two options contradict each other, one must be wrong"

Wrong. Options are independent. Two "opposite" options can both be true if they apply to different aspects of care.

Practice Tips for SATA Mastery

  • Drill daily: Do 10-15 SATA questions every day for 2 weeks. Pattern recognition develops fast.
  • Read rationales: Even when you get it right, read why each option is true or false.
  • Time yourself: SATA takes longer. Budget 90 seconds per question on the exam.
  • Use the true/false mantra: "Is this statement TRUE for this patient?"

From the ER: SATA questions mirror real nursing more than any other NCLEX format. In the emergency room, you don't pick one action — you do EVERYTHING that's appropriate. SATA trains you to think this way.
